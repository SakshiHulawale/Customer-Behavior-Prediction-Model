# Customer-Behavior-Prediction-Model
End-to-end ML pipeline on the Kaggle Instacart dataset (32M+ orders) to predict customer repurchases. Logistic Regression performed best (F1: 0.41, Recall: 0.79, ROC-AUC: 0.69). Includes adaptive sampling for scale, real-time APIs, and dashboards to visualize customer segments and revenue uplift.
Kaggle Dataset: https://www.kaggle.com/datasets/psparks/instacart-market-basket-analysis
